## 🚀 Tổng quan dự án
MoneyNest là ứng dụng di động giúp bạn kiểm soát chi tiêu, lập ngân sách, quản lý ví và giao dịch một cách thông minh, dễ dùng. Xây dựng bằng Flutter, MoneyNest tối ưu trải nghiệm cho cả điện thoại và máy tính bảng.

---

## ✨ Tính năng nổi bật hiện có

| Tính năng                | Mô tả                                                                 |
|------------------------- |-----------------------------------------------------------------------|
| **Quản lý ví**           | Tạo, sửa, xóa ví, hỗ trợ nhiều loại tiền tệ (mặc định VND)            |
| **Quản lý giao dịch**    | Thêm, sửa, xóa, lọc và tìm kiếm giao dịch thu/chi                     |
| **Quản lý danh mục**     | Tạo, sửa, xóa danh mục & danh mục con cho các khoản thu/chi           |
| **Quản lý ngân sách**    | Thiết lập ngân sách, theo dõi tiến độ chi tiêu                        |
| **Thống kê & báo cáo**   | Báo cáo tổng quan, biểu đồ thu/chi, phân tích theo danh mục/thời gian |
| **Chuyển đổi ví nhanh**  | Chuyển đổi, chọn ví khi tạo giao dịch                                 |
| **Đăng nhập/Đăng ký**    | Xác thực người dùng an toàn                                           |
| **Cài đặt ứng dụng**     | Tuỳ chỉnh ngôn ngữ, đơn vị tiền, giao diện                            |
